# React + Vite
🎨 Personal Portfolio - Built with React & Framer Motion
Welcome to my Personal Portfolio! 🚀 This project is a showcase of my skills, experiences, and projects, built with React for a smooth and dynamic experience, and Framer Motion to add stunning animations and interactions. 

Features ✨
Interactive UI: The portfolio features a user-friendly and interactive layout built with React.
Smooth Animations: With Framer Motion, you can enjoy smooth page transitions and interactive animations.
Project Showcase: A dedicated section where I highlight my key projects, complete with details and links.
Responsive Design: The portfolio is fully responsive, making it accessible on all screen sizes.
